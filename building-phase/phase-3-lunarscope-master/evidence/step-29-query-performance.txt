Dashboard query on one year of data
===================================

Data: 10 agents x 5 checks x hourly for 365 days = 438,000 rows in scan_results
(generated with a recursive CTE in sqlite3 3.51.2; database file 58 MB).

1) First version: window function over scan_results
----------------------------------------------------
WITH latest AS (SELECT agent_id, severity, ROW_NUMBER() OVER (
    PARTITION BY agent_id, scan_type, check_name ORDER BY timestamp DESC, id DESC) AS rn
  FROM scan_results)
SELECT ... FROM agents a LEFT JOIN latest l ON l.agent_id = a.id AND l.rn = 1 GROUP BY a.id
