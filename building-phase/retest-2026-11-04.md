### Finding: unclear agent error without `ca-certificates`

On a system without CA certificates the agent stops at startup with:

```text
lunarscope-agent: invalid config value: could not create HTTP client: builder error
```

- **Impact:** low. A normal Ubuntu 24.04 server install includes
  `ca-certificates`, and the agent can't verify the master's Let's Encrypt
  certificate without it anyway. Stopping is the right behaviour.
- **Problem:** the message is misleading. It says "invalid config value"
  although the config is fine, and it doesn't name the real cause.
- **Suggested fix (not done yet, because v0.1.0 is already tagged):**
  1. Report the error chain (as `error_chain()` already does for request
     errors, agent step 16) and add a hint such as "is the ca-certificates
     package installed?".
  2. Use a separate error kind instead of `ConfigError::Invalid`.
  3. Release it as `v0.1.1`.

  The agent's install instructions (step 20) should also list
  `ca-certificates` as a requirement.
